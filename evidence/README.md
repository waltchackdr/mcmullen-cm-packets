# Evidence selection

[index.json](index.json) identifies retained objects included in this edition
and objects omitted from it. Included objects keep their original SHA256 names
and bytes. Omitted objects are represented by digest and size, without private
working-path aliases. No omitted object is represented as verified.

The selection favors mathematical source and data. It omits private operational
records, correspondence, raw review conversations and unreviewed source captures.
The original archive is retained separately. This is not a complete historical
runtime, recursive dependency closure or replacement for the papers' proofs.

The [claim register](../docs/claim-register.md) connects statements and premises
to direct reference identities. Its JSON records distinguish original-path
files, retained objects and omitted references. The two genuinely missing
historical versions are listed separately in [limitations](../docs/limitations.md).

Historical objects are never executed automatically. Do not copy one over a
current file solely because their names resemble one another.
