# Certificate sources

These exact-check programs and supporting data retain their established names.
Start with the [claim register](../docs/claim-register.md) to identify a specific
certificate, its input version, mathematical scope and execution premises.

Placement in this directory or a passing run alone does not establish a theorem.
A finite search needs a proved domain and exact comparisons. Historical programs
may depend on unshipped inputs; consult [evidence availability](../evidence/README.md)
and the [reproduction guide](../docs/reproducing-results.md) before execution.

Do not infer current status from a version suffix or change an expected hash
after a failed check. [Separate implementations](../independent/README.md) have
their own recorded independence assumptions.
