# Data and claim navigation

[claims/register.json](claims/register.json) contains the derived public claim
view: stable IDs, qualifications, paper locations and direct-reference digests.
Private historical prose is not embedded in this file.

[catalog.json](catalog.json) records selected mathematical data entry points
and whether each is included. Entries are neither complete datasets nor claims
of complete dependency closure. Follow the [evidence guide](../evidence/README.md)
and [reproduction instructions](../docs/reproducing-results.md).
