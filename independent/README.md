# Separate implementations

These sources retain separately authored checks under stable identifiers.
Independence is an argument about derivation and dependencies; a different
language or directory alone does not establish it.

Use the [claim register](../docs/claim-register.md) to locate the relevant
scope, inputs and evidence. The selection does not imply that every script runs
standalone or that a new independent review has been performed.

Follow the [reproduction guide](../docs/reproducing-results.md), preserve source
identities, and distinguish exact cross-checks from mathematical proof.
